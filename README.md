## What the Tool Does

AI Incident Root Cause Analysis Tool is a web application for examining incident information with help from AI. It gives users a focused workflow for reviewing what happened, considering contributing factors, and exploring potential underlying causes.

Built for both individuals and teams, the tool provides a structured space for incident investigation and root cause analysis. Because it runs in a browser, it can be used without a conventional desktop installation.
